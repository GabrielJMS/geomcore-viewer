# geomcore-viewer v2 — Phase 4: Rust Client v2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `clients/rust` speak protocol v2 with the same semantics as the Python client (spec §7). That means:
- typed geometry (`Geom`, mirroring SCENE.md's table) and objects;
- a `Viewer` with runs, labels, groups, palette, surface windows, `update`/`remove`/`clear`/`save`, and `pcurve`;
- the same server discovery, minus spawning: one warning and local buffering when no server answers, and the tunnel hint on a 403;
- conversions from geomcore's Rust types behind an optional `geomcore` cargo feature.

v1 goes away: the crate's `Entity`/`Client` and the server's `POST /api/add`.

**Architecture:**
- `clients/rust/src/` is split by concern. `geom.rs` holds the wire geometry and its validation. `object.rs` holds style, options, objects and the palette. `http.rs` is std-only HTTP/1.1 plus the health probe. `viewer.rs` holds the scene state and the flush protocol, ported from `python/geomcore_viewer/viewer.py`. `convert.rs` (feature `geomcore`) turns geomcore types into `Geom`.
- Everything is unit-tested in-crate. HTTP and the viewer run against a scripted stub server on an ephemeral port. Conversions are checked against geomcore's `eval_point` at 1e-9.
- Two cross-checks tie the crate to the rest of the repo:
  - A committed scene fixture (`clients/rust/tests/scene.json`, one object of every kind) is regenerated by a Rust test and parsed by a vitest test with the viewer's own `parseDoc`.
  - `scripts/rust-live-check.sh` runs the examples against the real Python server in CI.

**Tech Stack:**
- Rust: edition 2021, `serde_json` 1 only, plus optional `geomcore` 0.28 from crates.io. geomcore is edition 2024, so the feature needs Rust ≥ 1.85; the dev machine has 1.96.1 and CI uses stable.
- Python: stdlib-only, pytest. Frontend: vitest 3 (node environment).

**Spec:** `docs/superpowers/specs/2026-10-10-viewer-v2-design.md` §7 (Rust client) and §8 (phase 4, with docs and examples), using the protocol of §4 as Phase 3 leaves it (`pcurve`).

**Depends on Phase 3 being merged first.** The `pcurve` object this client sends, `{"type": "pcurve", "surface": <id>, "curve": <line|circle|polyline in z = 0>}`, is Phase 3's wire type. Before Phase 3, the Task 5 vitest check fails on exactly the two pcurve objects; this was verified both ways while planning.

## Review Focus

The spec does not list these five inputs, but each is likely to hurt a real user. Each line names the owning task's test.

1. **No server, or a server that dies and comes back.** `add` must not fail. One warning says how to start the server (`python -m geomcore_viewer serve --port N`), objects stay local and `save` still works. When the server answers again, the whole scene goes out again with the run id. *Tests:* Task 3 `without_a_server_objects_are_kept_and_one_warning_says_how_to_start_it`, `a_server_that_comes_back_gets_the_whole_scene_again`.
2. **The wrong thing on the port:**
   - a port-changing SSH tunnel answers 403 with `"app": "geomcore-viewer"`;
   - something else answers (e.g. a Vite dev server on 8799);
   - something accepts the connection but never answers.

   Each case needs its own message, and the last must not block longer than the 0.5 s probe. *Tests:* Task 2 `probe_tells_who_answers`, `probe_gives_up_on_a_server_that_never_answers`; Task 3 `a_server_that_refuses_the_host_gets_the_tunnel_hint`.
3. **NaN from a numeric computation.** `serde_json` silently writes a non-finite `f64` as `null`, which the viewer would then reject as "malformed". `add` must return `Error::Invalid` before anything changes. *Tests:* Task 1 `problems_are_found_before_sending`, Task 3 `invalid_input_changes_nothing`.
4. **Subscripted labels in URLs.** Deleting `P₁` must percent-encode the id (`/api/objects/P%E2%82%81`), or the server answers 404 and the stale point stays on screen. *Test:* Task 3 `re_adding_a_label_replaces_what_it_showed`.
5. **geomcore conventions drifting from the protocol:**
   - a mirrored (left-handed) circle;
   - a cone whose `ref_radius` is 0;
   - a clockwise `Circle2D` (geomcore's `Frame2D` accepts either handedness);
   - tilted surfaces.

   These must still evaluate exactly as geomcore does. *Tests:* Task 4 `analytic_curves_evaluate_like_geomcore`, `a_mirrored_circle_still_evaluates_like_geomcore`, `analytic_surfaces_evaluate_like_geomcore`, `a_clockwise_2d_circle_keeps_its_direction`.

## Rulings Recorded While Planning

- **Rust never starts the server** (spec §7). The warning names the command, with the port taken from the URL.
- **The crate's v1 API is removed outright** (`Entity`, `Client`; version 0.1.0 → 0.2.0).
  - The server drops `POST /api/add`, and `/api/objects` now rejects v1 entities (`kind` without `geom`) with 400.
  - The page still loads v1 *documents* (drag-drop, `?scene=`): that migration lives in the frontend and is untouched.
- **Run ids** are 12 hex digits from std's randomly keyed `RandomState` hasher over time and pid. This adds no `rand` dependency and has the same shape as Python's `uuid4().hex[:12]`.
- **Frames come from geomcore's getters** (`frame()`, `origin()`, `x_direction()`…). The Python adapter recovers them by evaluation instead, because geomcore-py exposes no frames. The Rust conversion sends all three axes as given, so even a left-handed geomcore frame evaluates identically; the test checks this with a mirrored circle.
- **`Circle2D` keeps its own frame**: x from the frame, y from the frame, z = x × y, which can be −z for a clockwise frame. The circle's parameter `t` then matches geomcore's.
- **Intersection results are not mapped.** geomcore's Rust API returns about 30 typed result enums. The examples show the pattern instead: match the result and pass its points to `add_all`, which labels them `P₁`, `P₂`, …. The Rust client therefore sends no `meta` (`tag`/`params`) and no `source`; the 2D tooltip simply shows no parameters for those points.
- **B-splines are sampled**, as in Python: a curve as a 256-segment polyline over `bounds()`, a surface as a 48 × 48 mesh. Unlike geomcore-py, Rust has `u_bounds()`/`v_bounds()`, so a B-spline surface needs no `u=`/`v=`.
  - A geomcore curve or surface kind added later (the enums are `#[non_exhaustive]`) gets the same sampling through the traits. Infinite bounds are clamped to ±100.
- **`Handle` is a plain id.** `update`/`remove` go through `&mut Viewer` (`view.update(&h, Style::new().color("red"))`), so no shared ownership or interior mutability is needed.
- **URLs** must be `http://host[:port][/]`. A URL without a port means 80, as `http://` says and as Python does. https and base paths are rejected with `Error::Url`.
- **Validation before sending** goes further than Python's NaN check. Non-positive radii, a zero direction, short polylines, bad meshes and pcurves that are not a line/circle/polyline are refused locally with the viewer's own wording.
- **Formatting:** `clients/rust/rustfmt.toml` sets `max_width = 120` and `use_small_heuristics = "Max"`, and CI runs `cargo fmt --check`.
- **Not published to crates.io** in this phase. The READMEs show a git dependency.
- geomcore's `docs/viewer.md` is out of scope: the sibling repository is not touched.

```rust
//! Protocol v2 geometry (`protocol/SCENE.md`, "Geometry types").

use serde_json::{json, Map, Value};

/// `[x, y, z]`; a 2D point is `[x, y, 0.0]`.
pub type Vec3 = [f64; 3];

/// A placement: origin `o` and the unit axes `x`, `y`, `z` (right-handed, orthonormal).
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Frame {
    pub o: Vec3,
    pub x: Vec3,
    pub y: Vec3,
    pub z: Vec3,
}

impl Frame {
    /// The world axes at the origin.
    pub const WORLD: Frame = Frame { o: [0.0; 3], x: [1.0, 0.0, 0.0], y: [0.0, 1.0, 0.0], z: [0.0, 0.0, 1.0] };

    /// The world axes moved to `o`.
    pub fn at(o: Vec3) -> Frame {
        Frame { o, ..Frame::WORLD }
    }

    /// A right-handed frame at `o` with main axis `z` and `x` taken from `x_hint`
    /// (its part perpendicular to `z`). `None` when `z` is zero or parallel to `x_hint`.
    pub fn new(o: Vec3, z: Vec3, x_hint: Vec3) -> Option<Frame> {
        let z = unit(z)?;
        let x = unit(sub(x_hint, scale(z, dot(x_hint, z))))?;
        Some(Frame { o, x, y: cross(z, x), z })
    }

    fn to_json(self) -> Value {
        json!({"o": self.o, "x": self.x, "y": self.y, "z": self.z})
    }
}

/// A surface's parameter window; a missing direction is filled by [`crate::Viewer`]
/// (full period when closed, ± the scene's extent when infinite).
#[derive(Debug, Clone, Copy, PartialEq, Default)]
pub struct Window {
    pub u: Option<[f64; 2]>,
    pub v: Option<[f64; 2]>,
}

/// `note` severity.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum NoteLevel {
    #[default]
    Info,
    Warn,
}

/// One geometry, as on the wire. Curves take an optional parameter `range`,
/// surfaces a [`Window`]; the parametrizations are geomcore's (`protocol/SCENE.md`).
#[derive(Debug, Clone, PartialEq)]
#[non_exhaustive]
pub enum Geom {
    Line {
        o: Vec3,
        d: Vec3,
        range: Option<[f64; 2]>,
    },
    Circle {
        frame: Frame,
        r: f64,
        range: Option<[f64; 2]>,
    },
    Ellipse {
        frame: Frame,
        a: f64,
        b: f64,
        range: Option<[f64; 2]>,
    },
    Parabola {
        frame: Frame,
        f: f64,
        range: Option<[f64; 2]>,
    },
    Hyperbola {
        frame: Frame,
        a: f64,
        b: f64,
        range: Option<[f64; 2]>,
    },
    Polyline {
        points: Vec<Vec3>,
    },
    Plane {
        frame: Frame,
        window: Window,
    },
    Cylinder {
        frame: Frame,
        r: f64,
        window: Window,
    },
    Cone {
        frame: Frame,
        semi_angle: f64,
        ref_radius: f64,
        window: Window,
    },
    Sphere {
        frame: Frame,
        r: f64,
        window: Window,
    },
    /// `major` is the protocol's `R`, `minor` its `r`.
    Torus {
        frame: Frame,
        major: f64,
        minor: f64,
        window: Window,
    },
    Mesh {
        vertices: Vec<Vec3>,
        indices: Vec<u32>,
    },
    Point {
        p: Vec3,
    },
    Points {
        positions: Vec<Vec3>,
        size: Option<f64>,
    },
    Arrow {
        at: Vec3,
        vec: Vec3,
    },
    Text {
        at: Vec3,
        text: String,
    },
    Note {
        text: String,
        level: NoteLevel,
    },
    /// A curve in a surface's (u, v) parameter space: `curve` is a `Line`,
    /// `Circle` or `Polyline` in z = 0 whose x, y are read as u, v. Built by
    /// [`crate::Viewer::pcurve`], which fills `surface` with the surface's id.
    Pcurve {
        surface: String,
        curve: Box<Geom>,
    },
}

impl Geom {
    pub fn line(o: Vec3, d: Vec3) -> Geom {
        Geom::Line { o, d, range: None }
    }
    pub fn circle(frame: Frame, r: f64) -> Geom {
        Geom::Circle { frame, r, range: None }
    }
    pub fn ellipse(frame: Frame, a: f64, b: f64) -> Geom {
        Geom::Ellipse { frame, a, b, range: None }
    }
    pub fn parabola(frame: Frame, f: f64) -> Geom {
        Geom::Parabola { frame, f, range: None }
    }
    pub fn hyperbola(frame: Frame, a: f64, b: f64) -> Geom {
        Geom::Hyperbola { frame, a, b, range: None }
    }
    pub fn polyline(points: Vec<Vec3>) -> Geom {
        Geom::Polyline { points }
    }
    pub fn plane(frame: Frame) -> Geom {
        Geom::Plane { frame, window: Window::default() }
    }
    pub fn cylinder(frame: Frame, r: f64) -> Geom {
        Geom::Cylinder { frame, r, window: Window::default() }
    }
    pub fn cone(frame: Frame, semi_angle: f64, ref_radius: f64) -> Geom {
        Geom::Cone { frame, semi_angle, ref_radius, window: Window::default() }
    }
    pub fn sphere(frame: Frame, r: f64) -> Geom {
        Geom::Sphere { frame, r, window: Window::default() }
    }
    pub fn torus(frame: Frame, major: f64, minor: f64) -> Geom {
        Geom::Torus { frame, major, minor, window: Window::default() }
    }
    pub fn mesh(vertices: Vec<Vec3>, indices: Vec<u32>) -> Geom {
        Geom::Mesh { vertices, indices }
    }
    pub fn point(p: Vec3) -> Geom {
        Geom::Point { p }
    }
    pub fn points(positions: Vec<Vec3>) -> Geom {
        Geom::Points { positions, size: None }
    }
    pub fn arrow(at: Vec3, vec: Vec3) -> Geom {
        Geom::Arrow { at, vec }
    }
    pub fn text(at: Vec3, text: &str) -> Geom {
        Geom::Text { at, text: text.into() }
    }
    pub fn note(text: &str, level: NoteLevel) -> Geom {
        Geom::Note { text: text.into(), level }
    }

    /// A curve limited to `t0 ..= t1`; other geometry is returned unchanged.
    pub fn range(mut self, t0: f64, t1: f64) -> Geom {
        match &mut self {
            Geom::Line { range, .. }
            | Geom::Circle { range, .. }
            | Geom::Ellipse { range, .. }
            | Geom::Parabola { range, .. }
            | Geom::Hyperbola { range, .. } => *range = Some([t0, t1]),
            _ => {}
        }
        self
    }

    /// A surface limited to `u` × `v` (a `None` keeps the default); other geometry is returned unchanged.
    pub fn window(mut self, u: Option<[f64; 2]>, v: Option<[f64; 2]>) -> Geom {
        if let Some(w) = self.window_mut() {
            w.u = u.or(w.u);
            w.v = v.or(w.v);
        }
        self
    }

    /// The protocol's `geom.type`.
    pub fn kind(&self) -> &'static str {
        match self {
            Geom::Line { .. } => "line",
            Geom::Circle { .. } => "circle",
            Geom::Ellipse { .. } => "ellipse",
            Geom::Parabola { .. } => "parabola",
            Geom::Hyperbola { .. } => "hyperbola",
            Geom::Polyline { .. } => "polyline",
            Geom::Plane { .. } => "plane",
            Geom::Cylinder { .. } => "cylinder",
            Geom::Cone { .. } => "cone",
            Geom::Sphere { .. } => "sphere",
            Geom::Torus { .. } => "torus",
            Geom::Mesh { .. } => "mesh",
            Geom::Point { .. } => "point",
            Geom::Points { .. } => "points",
            Geom::Arrow { .. } => "arrow",
            Geom::Text { .. } => "text",
            Geom::Note { .. } => "note",
            Geom::Pcurve { .. } => "pcurve",
        }
    }

    pub fn is_surface(&self) -> bool {
        matches!(
            self,
            Geom::Plane { .. } | Geom::Cylinder { .. } | Geom::Cone { .. } | Geom::Sphere { .. } | Geom::Torus { .. }
        )
    }

    pub(crate) fn window_mut(&mut self) -> Option<&mut Window> {
        match self {
            Geom::Plane { window, .. }
            | Geom::Cylinder { window, .. }
            | Geom::Cone { window, .. }
            | Geom::Sphere { window, .. }
            | Geom::Torus { window, .. } => Some(window),
            _ => None,
        }
    }

    /// Why the viewer would reject this geometry, checked before anything is sent:
    /// a non-finite number, a radius that is not positive, a zero direction,
    /// too few points or a malformed mesh or pcurve.
    pub fn problem(&self) -> Option<String> {
        let mut nums: Vec<f64> = Vec::new();
        self.numbers(&mut nums);
        if nums.iter().any(|x| !x.is_finite()) {
            return Some(format!("{} has NaN or infinite values", self.kind()));
        }
        let kind = self.kind();
        let positive = |name: &str, x: f64| (x <= 0.0).then(|| format!("{kind}.{name} must be positive"));
        match self {
            Geom::Line { d, .. } if *d == [0.0; 3] => Some("line.d must be non-zero".into()),
            Geom::Circle { r, .. } | Geom::Cylinder { r, .. } | Geom::Sphere { r, .. } => positive("r", *r),
            Geom::Ellipse { a, b, .. } | Geom::Hyperbola { a, b, .. } => {
                positive("a", *a).or_else(|| positive("b", *b))
            }
            Geom::Torus { major, minor, .. } => positive("R", *major).or_else(|| positive("r", *minor)),
            Geom::Parabola { f, .. } if *f == 0.0 => Some("parabola.f must be non-zero".into()),
            Geom::Polyline { points } if points.len() < 2 => Some("polyline.points needs at least 2 points".into()),
            Geom::Points { positions, .. } if positions.is_empty() => Some("points.positions must not be empty".into()),
            Geom::Mesh { vertices, indices } => {
                let n = vertices.len();
                (indices.is_empty() || indices.len() % 3 != 0 || indices.iter().any(|&i| i as usize >= n))
                    .then(|| "mesh.indices must be triangles indexing vertices".into())
            }
            Geom::Pcurve { curve, .. } => match **curve {
                Geom::Line { .. } | Geom::Circle { .. } | Geom::Polyline { .. } => curve.problem(),
                _ => Some(format!("a pcurve is a line, circle or polyline in (u, v), got {}", curve.kind())),
            },
            _ => None,
        }
    }

    fn numbers(&self, out: &mut Vec<f64>) {
        let frame = |out: &mut Vec<f64>, f: &Frame| [f.o, f.x, f.y, f.z].iter().for_each(|v| out.extend(v));
        let pair = |out: &mut Vec<f64>, r: &Option<[f64; 2]>| out.extend(r.iter().flatten());
        let window = |out: &mut Vec<f64>, w: &Window| {
            pair(out, &w.u);
            pair(out, &w.v)
        };
        match self {
            Geom::Line { o, d, range } => {
                out.extend(o.iter().chain(d));
                pair(out, range)
            }
            Geom::Circle { frame: f, r, range } => {
                frame(out, f);
                out.push(*r);
                pair(out, range)
            }
            Geom::Ellipse { frame: f, a, b, range } | Geom::Hyperbola { frame: f, a, b, range } => {
                frame(out, f);
                out.extend([*a, *b]);
                pair(out, range)
            }
            Geom::Parabola { frame: f, f: focal, range } => {
                frame(out, f);
                out.push(*focal);
                pair(out, range)
            }
            Geom::Polyline { points } => points.iter().for_each(|p| out.extend(p)),
            Geom::Plane { frame: f, window: w } => {
                frame(out, f);
                window(out, w)
            }
            Geom::Cylinder { frame: f, r, window: w } | Geom::Sphere { frame: f, r, window: w } => {
                frame(out, f);
                out.push(*r);
                window(out, w)
            }
            Geom::Cone { frame: f, semi_angle, ref_radius, window: w } => {
                frame(out, f);
                out.extend([*semi_angle, *ref_radius]);
                window(out, w)
            }
            Geom::Torus { frame: f, major, minor, window: w } => {
                frame(out, f);
                out.extend([*major, *minor]);
                window(out, w)
            }
            Geom::Mesh { vertices, .. } => vertices.iter().for_each(|p| out.extend(p)),
            Geom::Point { p } => out.extend(p),
            Geom::Points { positions, size } => {
                positions.iter().for_each(|p| out.extend(p));
                out.extend(size)
            }
            Geom::Arrow { at, vec } => out.extend(at.iter().chain(vec)),
            Geom::Text { at, .. } => out.extend(at),
            Geom::Note { .. } => {}
            Geom::Pcurve { curve, .. } => curve.numbers(out),
        }
    }

    /// The `geom` JSON object.
    pub fn to_json(&self) -> Value {
        let mut m = Map::new();
        m.insert("type".into(), self.kind().into());
        let mut put = |k: &str, v: Value| {
            m.insert(k.into(), v);
        };
        match self {
            Geom::Line { o, d, range } => {
                put("o", json!(o));
                put("d", json!(d));
                put_range(&mut put, range);
            }
            Geom::Circle { frame, r, range } => {
                put("frame", frame.to_json());
                put("r", json!(r));
                put_range(&mut put, range);
            }
            Geom::Ellipse { frame, a, b, range } | Geom::Hyperbola { frame, a, b, range } => {
                put("frame", frame.to_json());
                put("a", json!(a));
                put("b", json!(b));
                put_range(&mut put, range);
            }
            Geom::Parabola { frame, f, range } => {
                put("frame", frame.to_json());
                put("f", json!(f));
                put_range(&mut put, range);
            }
            Geom::Polyline { points } => put("points", json!(points)),
            Geom::Plane { frame, window } => {
                put("frame", frame.to_json());
                put_window(&mut put, window);
            }
            Geom::Cylinder { frame, r, window } | Geom::Sphere { frame, r, window } => {
                put("frame", frame.to_json());
                put("r", json!(r));
                put_window(&mut put, window);
            }
            Geom::Cone { frame, semi_angle, ref_radius, window } => {
                put("frame", frame.to_json());
                put("semi_angle", json!(semi_angle));
                put("ref_radius", json!(ref_radius));
                put_window(&mut put, window);
            }
            Geom::Torus { frame, major, minor, window } => {
                put("frame", frame.to_json());
                put("R", json!(major));
                put("r", json!(minor));
                put_window(&mut put, window);
            }
            Geom::Mesh { vertices, indices } => {
                put("vertices", json!(vertices));
                put("indices", json!(indices));
            }
            Geom::Point { p } => put("p", json!(p)),
            Geom::Points { positions, size } => {
                put("positions", json!(positions));
                if let Some(s) = size {
                    put("size", json!(s));
                }
            }
            Geom::Arrow { at, vec } => {
                put("at", json!(at));
                put("vec", json!(vec));
            }
            Geom::Text { at, text } => {
                put("at", json!(at));
                put("text", json!(text));
            }
            Geom::Note { text, level } => {
                put("text", json!(text));
                put("level", json!(if *level == NoteLevel::Warn { "warn" } else { "info" }));
            }
            Geom::Pcurve { surface, curve } => {
                put("surface", json!(surface));
                put("curve", curve.to_json());
            }
        }
        Value::Object(m)
    }
}

fn put_range(put: &mut impl FnMut(&str, Value), range: &Option<[f64; 2]>) {
    if let Some(r) = range {
        put("range", json!(r));
    }
}

fn put_window(put: &mut impl FnMut(&str, Value), w: &Window) {
    if w.u.is_none() && w.v.is_none() {
        return;
    }
    let mut m = Map::new();
    if let Some(u) = w.u {
        m.insert("u".into(), json!(u));
    }
    if let Some(v) = w.v {
        m.insert("v".into(), json!(v));
    }
    put("window", Value::Object(m));
}

pub(crate) fn dot(a: Vec3, b: Vec3) -> f64 {
    a[0] * b[0] + a[1] * b[1] + a[2] * b[2]
}

pub(crate) fn sub(a: Vec3, b: Vec3) -> Vec3 {
    [a[0] - b[0], a[1] - b[1], a[2] - b[2]]
}

pub(crate) fn scale(a: Vec3, s: f64) -> Vec3 {
    [a[0] * s, a[1] * s, a[2] * s]
}

pub(crate) fn cross(a: Vec3, b: Vec3) -> Vec3 {
    [a[1] * b[2] - a[2] * b[1], a[2] * b[0] - a[0] * b[2], a[0] * b[1] - a[1] * b[0]]
}

pub(crate) fn norm(a: Vec3) -> f64 {
    dot(a, a).sqrt()
}

fn unit(a: Vec3) -> Option<Vec3> {
    let n = norm(a);
    (n > 1e-12 && n.is_finite()).then(|| scale(a, 1.0 / n))
}
```

use serde_json::{json, Map, Value};

use crate::geom::Geom;

/// Categorical palette, the Python client's: every colour has contrast ≥ 3:1 on the
/// viewer's light (#f7f8fa) and dark (#16181d) backgrounds.
pub const PALETTE: [&str; 8] = ["#d1495b", "#00798c", "#c47f00", "#3a7cc2", "#8a5cc2", "#5c8a00", "#b5448f", "#6b7a8f"];

/// Extras the viewer draws: curves `foci`, `center`, `axes`, `asymptotes`, `directrix`,
/// `vertex`; surfaces `isolines` (`[nu, nv]`) and `wire`.
pub const EXTRAS: [&str; 8] = ["foci", "center", "axes", "asymptotes", "directrix", "vertex", "isolines", "wire"];

/// `color` (CSS), `width` (px), `dashed`, `opacity` (0–1); unset fields keep the viewer's default.
#[derive(Debug, Clone, Default, PartialEq)]
pub struct Style {
    pub color: Option<String>,
    pub width: Option<f64>,
    pub dashed: Option<bool>,
    pub opacity: Option<f64>,
}

impl Style {
    pub fn new() -> Style {
        Style::default()
    }
    pub fn color(mut self, css: &str) -> Style {
        self.color = Some(css.into());
        self
    }
    pub fn width(mut self, px: f64) -> Style {
        self.width = Some(px);
        self
    }
    pub fn dashed(mut self, dashed: bool) -> Style {
        self.dashed = Some(dashed);
        self
    }
    pub fn opacity(mut self, opacity: f64) -> Style {
        self.opacity = Some(opacity);
        self
    }

    /// `self` with every field `over` sets replaced.
    pub(crate) fn merged(&self, over: &Style) -> Style {
        Style {
            color: over.color.clone().or_else(|| self.color.clone()),
            width: over.width.or(self.width),
            dashed: over.dashed.or(self.dashed),
            opacity: over.opacity.or(self.opacity),
        }
    }

    /// Why the viewer would reject this style: a width that is not a positive number,
    /// an opacity outside 0–1.
    pub fn problem(&self) -> Option<String> {
        match (self.width, self.opacity) {
            (Some(w), _) if !(w.is_finite() && w > 0.0) => {
                Some(format!("style.width must be a positive number, got {w}"))
            }
            (_, Some(o)) if !(0.0..=1.0).contains(&o) => Some(format!("style.opacity must be within 0–1, got {o}")),
            _ => None,
        }
    }

    fn to_json(&self) -> Value {
        let mut m = Map::new();
        if let Some(c) = &self.color {
            m.insert("color".into(), json!(c));
        }
        if let Some(w) = self.width {
            m.insert("width".into(), json!(w));
        }
        if let Some(d) = self.dashed {
            m.insert("dashed".into(), json!(d));
        }
        if let Some(o) = self.opacity {
            m.insert("opacity".into(), json!(o));
        }
        Value::Object(m)
    }

/// How to show what [`crate::Viewer::add`] adds: label, group, style and extras.
///
/// ```
/// use geomcore_viewer::Opts;
/// let opts = Opts::new().label("E").group("conics").color("#d1495b").extra("foci", true);
/// # let _ = opts;
/// ```
#[derive(Debug, Clone, Default, PartialEq)]
pub struct Opts {
    pub(crate) label: Option<String>,
    pub(crate) group: Option<String>,
    pub(crate) style: Style,
    pub(crate) extras: Map<String, Value>,
}

impl Opts {
    pub fn new() -> Opts {
        Opts::default()
    }
    /// Display name, and the object's id: re-adding a label replaces what it showed before.
    pub fn label(mut self, label: &str) -> Opts {
        self.label = Some(label.into());
        self
    }
    /// Panel group (one visibility toggle for all its objects).
    pub fn group(mut self, group: &str) -> Opts {
        self.group = Some(group.into());
        self
    }
    pub fn style(mut self, style: Style) -> Opts {
        self.style = self.style.merged(&style);
        self
    }
    pub fn color(self, css: &str) -> Opts {
        self.style(Style::new().color(css))
    }
    pub fn width(self, px: f64) -> Opts {
        self.style(Style::new().width(px))
    }
    pub fn dashed(self, dashed: bool) -> Opts {
        self.style(Style::new().dashed(dashed))
    }
    pub fn opacity(self, opacity: f64) -> Opts {
        self.style(Style::new().opacity(opacity))
    }
    /// One of [`EXTRAS`], e.g. `extra("foci", true)` or `extra("isolines", [8, 4])`.
    pub fn extra(mut self, name: &str, value: impl Into<Value>) -> Opts {
        self.extras.insert(name.into(), value.into());
        self
    }

    /// Why [`crate::Viewer::add`] would reject these options: an unknown extra or a bad style.
    pub fn problem(&self) -> Option<String> {
        if let Some(name) = self.extras.keys().find(|k| !EXTRAS.contains(&k.as_str())) {
            return Some(format!("unknown extra {name:?} (expected one of {})", EXTRAS.join(", ")));
        }
        self.style.problem()
    }
}

/// One object of the scene, as on the wire.
#[derive(Debug, Clone, PartialEq)]
pub struct Object {
    pub id: String,
    pub geom: Geom,
    pub label: Option<String>,
    pub group: Option<String>,
    /// Absent on notes, which have no style.
    pub style: Option<Style>,
    pub extras: Map<String, Value>,
}

impl Object {
    pub fn to_json(&self) -> Value {
        let mut m = Map::new();
        m.insert("id".into(), json!(self.id));
        m.insert("geom".into(), self.geom.to_json());
        if let Some(label) = &self.label {
            m.insert("label".into(), json!(label));
        }
        if let Some(group) = &self.group {
            m.insert("group".into(), json!(group));
        }
        if let Some(style) = &self.style {
            m.insert("style".into(), style.to_json());
        }
        if !self.extras.is_empty() {
            m.insert("extras".into(), Value::Object(self.extras.clone()));
        }
        Value::Object(m)
    }
}

/// `P` → `P₃`; a label that already ends in a subscript gets a comma, `P₁` → `P₁,₃`
/// (the Python client's `indexed`).
pub fn indexed(label: &str, i: usize) -> String {
    const DIGITS: [char; 10] = ['₀', '₁', '₂', '₃', '₄', '₅', '₆', '₇', '₈', '₉'];
    let sub: String = i.to_string().chars().map(|c| DIGITS[c.to_digit(10).unwrap() as usize]).collect();
    if label.chars().last().is_some_and(|c| DIGITS.contains(&c)) {
        format!("{label},{sub}")
    } else {
        format!("{label}{sub}")
    }
}

### Task 2: HTTP transport and server discovery

The v1 client read only 12 bytes of each response, so it could neither report a server's error nor tell a geomcore-viewer from another program. This task adds a small std-only HTTP/1.1 client and the URL rules. It also adds `probe`, which classifies what answers at the URL the same way Python's `spawn.probe` does. Tests run against a scripted stub server on an ephemeral port; Task 3 reuses the stub.

**Interfaces:**

```rust
//! Just enough HTTP/1.1 for the viewer's local API, on `std` alone.

use std::io::{self, Read, Write};
use std::net::{TcpStream, ToSocketAddrs};
use std::time::Duration;

use serde_json::Value;

pub(crate) const APP: &str = "geomcore-viewer";
pub(crate) const PROTOCOL: u64 = 2;

/// Where the server listens, from an `http://host[:port][/]` URL.
#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct Endpoint {
    pub host: String,
    pub port: u16,
}

impl Endpoint {
    /// A URL without a port means port 80, as `http://` says.
    pub fn parse(url: &str) -> Result<Endpoint, String> {
        let rest = url.strip_prefix("http://").ok_or_else(|| format!("{url:?}: only http:// URLs are supported"))?;
        let authority = rest.strip_suffix('/').unwrap_or(rest);
        if authority.contains('/') {
            return Err(format!("{url:?}: the URL must not have a path"));
        }
        let (host, port) = match authority.rsplit_once(':') {
            Some((host, port)) => {
                let port = port.parse::<u16>().map_err(|_| format!("{url:?} has a malformed port"))?;
                (host, port)
            }
            None => (authority, 80),
        };
        if host.is_empty() {
            return Err(format!("{url:?} has no host"));
        }
        Ok(Endpoint { host: host.into(), port })
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct Response {
    pub status: u16,
    pub body: String,
}

/// The request bytes: the server checks that `Host` names it, port included.
pub(crate) fn format_request(ep: &Endpoint, method: &str, path: &str, body: Option<&str>) -> String {
    let body = body.unwrap_or("");
    format!(
        "{method} {path} HTTP/1.1\r\nHost: {}:{}\r\nContent-Type: application/json\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{body}",
        ep.host,
        ep.port,
        body.len()
    )
}

/// One request and its whole response. Connection, timeout and read errors are
/// `io::Error`s; an answer that is not HTTP is `ErrorKind::InvalidData`.
pub(crate) fn request(
    ep: &Endpoint,
    method: &str,
    path: &str,
    body: Option<&str>,
    timeout: Duration,
) -> io::Result<Response> {
    let mut last = io::Error::new(io::ErrorKind::NotFound, format!("{} resolves to no address", ep.host));
    let mut stream = None;
    for addr in (ep.host.as_str(), ep.port).to_socket_addrs()? {
        match TcpStream::connect_timeout(&addr, timeout) {
            Ok(s) => {
                stream = Some(s);
                break;
            }
            Err(err) => last = err,
        }
    }
    let mut stream = stream.ok_or(last)?;
    stream.set_read_timeout(Some(timeout))?;
    stream.set_write_timeout(Some(timeout))?;
    stream.write_all(format_request(ep, method, path, body).as_bytes())?;
    let mut raw = Vec::new();
    stream.read_to_end(&mut raw)?;
    parse_response(&raw).ok_or_else(|| io::Error::new(io::ErrorKind::InvalidData, "not an HTTP response"))
}

fn parse_response(raw: &[u8]) -> Option<Response> {
    let split = raw.windows(4).position(|w| w == b"\r\n\r\n")?;
    let head = std::str::from_utf8(&raw[..split]).ok()?;
    let mut lines = head.split("\r\n");
    let mut status_line = lines.next()?.split_whitespace();
    if !status_line.next()?.starts_with("HTTP/1.") {
        return None;
    }
    let status = status_line.next()?.parse().ok()?;
    let mut body = &raw[split + 4..];
    for line in lines {
        if let Some((name, value)) = line.split_once(':') {
            if name.trim().eq_ignore_ascii_case("content-length") {
                let n: usize = value.trim().parse().ok()?;
                body = body.get(..n)?; // a body cut short is not a whole response
            }
        }
    }
    Some(Response { status, body: String::from_utf8_lossy(body).into_owned() })
}

/// What answers at an endpoint (Python: `spawn.probe`).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum Probe {
    /// A v2 geomcore-viewer.
    Ours,
    /// A geomcore-viewer that rejects this `Host` (a tunnel that changes the port).
    Refused,
    /// Something else.
    Foreign,
    /// Something accepts the connection but does not answer in time.
    Unresponsive,
    /// Nothing listens.
    Nothing,
}

pub(crate) fn probe(ep: &Endpoint, timeout: Duration) -> Probe {
    let res = match request(ep, "GET", "/api/health", None, timeout) {
        Ok(res) => res,
        Err(err) if err.kind() == io::ErrorKind::InvalidData => return Probe::Foreign,
        Err(err) if matches!(err.kind(), io::ErrorKind::TimedOut | io::ErrorKind::WouldBlock) => {
            return Probe::Unresponsive
        }
        Err(_) => return Probe::Nothing,
    };
    let doc: Value = serde_json::from_str(&res.body).unwrap_or(Value::Null);
    let ours = doc.get("app").and_then(Value::as_str) == Some(APP);
    match res.status {
        200 if ours && doc.get("protocol").and_then(Value::as_u64) == Some(PROTOCOL) => Probe::Ours,
        403 if ours => Probe::Refused,
        _ => Probe::Foreign,
    }
}

/// What to tell the user when a geomcore-viewer refuses `url` (Python: `spawn.refused_hint`).
pub(crate) fn refused_hint(url: &str, port: u16) -> String {
    format!(
        "the geomcore-viewer at {url} refused the request: it only answers to its own address, \
         so an SSH tunnel must keep the port (ssh -L {port}:127.0.0.1:{port} <host>)"
    )
}

pub(crate) mod stub {
    //! A scripted local server for tests: answers each request with `answer(method, path, body)`
    //! and records what it received.

    use std::io::{BufRead, BufReader, Read, Write};
    use std::net::TcpListener;
    use std::sync::{Arc, Mutex};
    use std::thread;

    pub type Seen = Arc<Mutex<Vec<(String, String, String)>>>;

    pub fn serve(answer: impl Fn(&str, &str, &str) -> (u16, String) + Send + 'static) -> (u16, Seen) {
        let listener = TcpListener::bind("127.0.0.1:0").unwrap();
        let port = listener.local_addr().unwrap().port();
        let seen: Seen = Arc::default();
        let log = Arc::clone(&seen);
        thread::spawn(move || {
            for stream in listener.incoming() {
                let mut stream = stream.unwrap();
                let mut reader = BufReader::new(stream.try_clone().unwrap());
                let mut line = String::new();
                reader.read_line(&mut line).unwrap();
                let mut parts = line.split_whitespace();
                let (method, path) = (parts.next().unwrap_or("").to_string(), parts.next().unwrap_or("").to_string());
                let mut length = 0;
                loop {
                    let mut header = String::new();
                    reader.read_line(&mut header).unwrap();
                    if header == "\r\n" || header.is_empty() {
                        break;
                    }
                    if let Some(v) = header.to_ascii_lowercase().strip_prefix("content-length:") {
                        length = v.trim().parse().unwrap();
                    }
                }
                let mut body = vec![0; length];
                reader.read_exact(&mut body).unwrap();
                let body = String::from_utf8(body).unwrap();
                let (status, reply) = answer(&method, &path, &body);
                log.lock().unwrap().push((method, path, body));
                let _ = write!(
                    stream,
                    "HTTP/1.0 {status} X\r\nContent-Type: application/json\r\nContent-Length: {}\r\n\r\n{reply}",
                    reply.len()
                );
            }
        });
        (port, seen)
    }

    /// A geomcore-viewer that accepts everything.
    pub fn viewer() -> (u16, Seen) {
        serve(|_, path, _| {
            let body =
                if path == "/api/health" { r#"{"app": "geomcore-viewer", "protocol": 2}"# } else { r#"{"ok": true}"# };
            (200, body.into())
        })
    }

    /// A port where nothing listens.
    pub fn closed_port() -> u16 {
        TcpListener::bind("127.0.0.1:0").unwrap().local_addr().unwrap().port()
    }
}
```

/// 12 hex digits, different for every viewer (std's randomly keyed hasher over time and pid).
fn run_id() -> String {
    let mut h = RandomState::new().build_hasher();
    h.write_u128(SystemTime::now().duration_since(UNIX_EPOCH).map_or(0, |d| d.as_nanos()));
    h.write_u32(std::process::id());
    format!("{:012x}", h.finish() & 0xffff_ffff_ffff)
}

impl Viewer {
    /// A viewer with the default options: the URL from `$GEOMCORE_VIEWER_URL`, `ViewMode::Auto`.
    pub fn new(title: &str) -> Result<Viewer, Error> {
        Viewer::builder(title).build()
    }

    pub fn builder(title: &str) -> Builder {
        Builder { title: title.into(), view: ViewMode::Auto, keep: false, url: None }
    }

    pub fn url(&self) -> &str {
        &self.url
    }

    /// This viewer's run id.
    pub fn run(&self) -> &str {
        &self.run
    }

    /// The objects in the scene, in the order they were first added.
    pub fn objects(&self) -> &[Object] {
        &self.objects
    }

    // -- adding --------------------------------------------------------------

    /// Show one geometry: a [`Geom`], or with the `geomcore` feature any geomcore
    /// curve, surface or point. A labelled object's id is its label, so re-adding a
    /// label replaces what it showed; an unlabelled one gets a fresh id.
    pub fn add(&mut self, geom: impl Into<Geom>, opts: Opts) -> Result<Handle, Error> {
        let label = opts.label.clone();
        let mut handles = self.commit(vec![(label.clone(), geom.into())], label, &opts)?;
        Ok(handles.remove(0))
    }

    /// Show several geometries under one label: `P` becomes `P₁`, `P₂`, … (the
    /// way the Python client shows an intersection's points). An empty list shows
    /// the note `P: ∅`.
    pub fn add_all<G: Into<Geom>>(
        &mut self,
        geoms: impl IntoIterator<Item = G>,
        opts: Opts,
    ) -> Result<Vec<Handle>, Error> {
        let geoms: Vec<Geom> = geoms.into_iter().map(Into::into).collect();
        let label = opts.label.clone();
        let parts = if geoms.is_empty() {
            let text = label.as_ref().map_or("∅".into(), |l| format!("{l}: ∅"));
            vec![(label.as_ref().map(|l| format!("{l}·note")), Geom::note(&text, NoteLevel::Info))]
        } else if geoms.len() == 1 {
            vec![(label.clone(), geoms.into_iter().next().unwrap())]
        } else {
            geoms.into_iter().enumerate().map(|(i, g)| (label.as_ref().map(|l| indexed(l, i + 1)), g)).collect()
        };
        self.commit(parts, label, &opts)
    }

    /// Show a curve of `on`'s (u, v) parameter space: a `Line`, `Circle` or
    /// `Polyline` whose x, y are u, v — with the `geomcore` feature, what
    /// `parametrize_on` returns. The viewer draws it on the surface in 3D and in
    /// the (u, v) pane.
    pub fn pcurve(&mut self, curve: impl Into<Geom>, on: &Handle, opts: Opts) -> Result<Handle, Error> {
        match self.objects.iter().find(|o| o.id == on.id) {
            Some(o) if o.geom.is_surface() => {}
            _ => return Err(Error::Invalid(format!("{}: a pcurve needs a surface of this scene", on.id))),
        }
        let geom = Geom::Pcurve { surface: on.id.clone(), curve: Box::new(curve.into()) };
        self.add(geom, opts)
    }

    fn commit(
        &mut self,
        parts: Vec<(Option<String>, Geom)>,
        family: Option<String>,
        opts: &Opts,
    ) -> Result<Vec<Handle>, Error> {
        if let Some(problem) = opts.problem() {
            return Err(Error::Invalid(problem));
        }
        if let Some(problem) = parts.iter().find_map(|(id, g)| g.problem().map(|p| (id, p))) {
            return Err(Error::Invalid(match problem {
                (Some(id), p) => format!("{id}: {p}"),
                (None, p) => p,
            }));
        }
        let mut built = Vec::new();
        for (id, geom) in parts {
            let id = id.unwrap_or_else(|| self.auto_id());
            built.push(self.build(id, geom, opts));
        }
        let ids: Vec<String> = built.iter().map(|o| o.id.clone()).collect();
        for obj in built {
            self.unsent.push(obj.id.clone());
            match self.objects.iter_mut().find(|o| o.id == obj.id) {
                Some(slot) => *slot = obj,
                None => self.objects.push(obj),
            }
        }
        if let Some(label) = family {
            for stale in self.families.remove(&label).unwrap_or_default() {
                if !ids.contains(&stale) {
                    self.forget(&stale);
                }
            }
            self.families.insert(label, ids.clone());
        }
        self.flush()?;
        Ok(ids.into_iter().map(|id| Handle { id }).collect())
    }

    fn build(&mut self, id: String, mut geom: Geom, opts: &Opts) -> Object {
        if geom.is_surface() {
            let extent = scene_extent(self.objects.iter().filter(|o| o.id != id).map(|o| &o.geom));
            fill_window(&mut geom, extent);
        }
        let style = match geom {
            Geom::Note { .. } => None,
            _ => {
                let previous = self
                    .objects
                    .iter()
                    .find(|o| o.id == id)
                    .and_then(|o| o.style.as_ref())
                    .and_then(|s| s.color.clone());
                let color = previous.unwrap_or_else(|| self.next_color());
                Some(Style::new().color(&color).merged(&opts.style))
            }
        };
        let label = match geom {
            Geom::Note { .. } => None,
            _ => opts.label.as_ref().map(|_| id.clone()),
        };
        Object { id, geom, label, group: opts.group.clone(), style, extras: opts.extras.clone() }
    }

    fn next_color(&mut self) -> String {
        let color = PALETTE[self.next_color % PALETTE.len()];
        self.next_color += 1;
        color.into()
    }

    fn auto_id(&mut self) -> String {
        self.next_auto += 1;
        format!("{}-{}", &self.run[..6], self.next_auto)
    }

    // -- changing and removing ---------------------------------------------------

    /// Change `color`, `width`, `dashed` or `opacity` in place.
    pub fn update(&mut self, handle: &Handle, style: Style) -> Result<(), Error> {
        if let Some(problem) = style.problem() {
            return Err(Error::Invalid(problem));
        }
        let obj = self
            .objects
            .iter_mut()
            .find(|o| o.id == handle.id)
            .ok_or_else(|| Error::Invalid(format!("{:?} is no longer in the scene", handle.id)))?;
        obj.style = Some(obj.style.clone().unwrap_or_default().merged(&style));
        self.unsent.push(handle.id.clone());
        self.flush()
    }

    pub fn remove(&mut self, handle: &Handle) -> Result<(), Error> {
        self.forget(&handle.id);
        self.flush()
    }

    /// Drop an object here and queue its deletion on the server (sent by `flush`).
    fn forget(&mut self, id: &str) {
        self.objects.retain(|o| o.id != id);
        self.unsent.retain(|i| i != id);
        if self.run_sent {
            self.pending_removals.push(id.into());
        }
    }

    /// Empty the scene, here and in the open tab.
    pub fn clear(&mut self) -> Result<(), Error> {
        self.objects.clear();
        self.families.clear();
        self.unsent.clear();
        self.pending_removals.clear();
        self.pending_clear = true;
        self.flush()
    }

    // -- persistence ---------------------------------------------------------------

    /// The scene document (`protocol/SCENE.md`).
    pub fn scene(&self) -> Value {
        json!({
            "version": http::PROTOCOL,
            "title": self.title,
            "run": self.run,
            "view": self.view.as_str(),
            "objects": self.objects.iter().map(Object::to_json).collect::<Vec<_>>(),
        })
    }

    /// Write the scene as JSON (open it with `?scene=` or drag-drop it on the page).
    pub fn save(&self, path: impl AsRef<Path>) -> Result<PathBuf, Error> {
        let path = path.as_ref().to_path_buf();
        std::fs::write(&path, self.scene().to_string())?;
        Ok(path)
    }

    // -- transport -------------------------------------------------------------------

    /// Bring the server up to date: pending clear, then deletes, then upserts.
    fn flush(&mut self) -> Result<(), Error> {
        if (self.unsent.is_empty() && self.pending_removals.is_empty() && !self.pending_clear) || !self.connect() {
            return Ok(());
        }
        if self.pending_clear {
            self.pending_clear = false;
            if !self.send("POST", "/api/clear", Some(json!({})), false)? {
                self.pending_clear = true;
                return Ok(());
            }
        }
        while let Some(id) = self.pending_removals.first().cloned() {
            if !self.send("DELETE", &format!("/api/objects/{}", encode(&id)), None, true)? {
                return Ok(());
            }
            self.pending_removals.remove(0);
        }
        if self.unsent.is_empty() {
            return Ok(());
        }
        let mut ids: Vec<String> = Vec::new();
        for id in &self.unsent {
            if !ids.contains(id) {
                ids.push(id.clone());
            }
        }
        let objects: Vec<Value> =
            ids.iter().filter_map(|id| self.objects.iter().find(|o| &o.id == id)).map(Object::to_json).collect();
        let mut batch = json!({"objects": objects, "title": self.title, "view": self.view.as_str()});
        if self.resync || !self.run_sent {
            batch["run"] = json!(self.run);
            batch["keep"] = json!(self.keep);
        }
        match self.send("POST", "/api/objects", Some(batch), false) {
            Ok(true) => {
                self.run_sent = true;
                self.resync = false;
                self.unsent.clear();
                Ok(())
            }
            Ok(false) => Ok(()),
            Err(err) => {
                // A rejected batch must not block every later add.
                self.unsent.retain(|i| !ids.contains(i));
                Err(err)
            }
        }
    }

    fn connect(&mut self) -> bool {
        if self.online {
            return true;
        }
        let keeping = "keeping objects locally (save() still works)";
        match http::probe(&self.endpoint, PROBE_TIMEOUT) {
            Probe::Ours => {
                self.online = true;
                self.warned = false; // a later outage deserves its own warning
            }
            Probe::Refused => self.warn(format!("{}; {keeping}", http::refused_hint(&self.url, self.endpoint.port))),
            Probe::Foreign => {
                self.warn(format!("{} answers but is not a geomcore-viewer v2 server; {keeping}", self.url))
            }
            Probe::Unresponsive => {
                self.warn(format!("{} accepted the connection but did not answer in time; {keeping}", self.url))
            }
            Probe::Nothing => self.warn(format!(
                "no geomcore-viewer at {}: start one with `python -m geomcore_viewer serve --port {}`; {keeping}",
                self.url, self.endpoint.port
            )),
        }
        self.online
    }

    /// `Ok(true)` when the server took the request, `Ok(false)` when it could not be
    /// reached (the whole scene goes out again once it is back), `Err` when it said no.
    fn send(&mut self, method: &str, path: &str, body: Option<Value>, missing_ok: bool) -> Result<bool, Error> {
        let body = body.map(|b| b.to_string());
        match http::request(&self.endpoint, method, path, body.as_deref(), REQUEST_TIMEOUT) {
            Ok(res) if res.status < 300 || (missing_ok && res.status == 404) => Ok(true),
            Ok(res) => Err(Error::Rejected { status: res.status, message: format!("{method} {path}: {}", res.body) }),
            Err(err) => {
                self.online = false;
                self.resync = self.run_sent;
                self.unsent = self.objects.iter().map(|o| o.id.clone()).collect();
                self.warn(format!("geomcore-viewer at {} is unreachable ({err}); keeping objects locally", self.url));
                Ok(false)
            }
        }
    }

    fn warn(&mut self, message: String) {
        if !self.warned {
            self.warned = true;
            eprintln!("geomcore-viewer: {message}");
            self.warnings.push(message);
        }
    }
}

/// Percent-encode an id for a URL path (everything but unreserved ASCII).
fn encode(id: &str) -> String {
    id.bytes()
        .map(|b| match b {
            b'A'..=b'Z' | b'a'..=b'z' | b'0'..=b'9' | b'-' | b'.' | b'_' | b'~' => (b as char).to_string(),
            _ => format!("%{b:02X}"),
        })
        .collect()
}

/// Half-size for infinite surface windows: 1.5 × the farthest finite feature from
/// the origin, or 5 for an empty scene (the Python client's `scene_extent`).
fn scene_extent<'a>(geoms: impl Iterator<Item = &'a Geom>) -> f64 {
    let mut reach: f64 = 0.0;
    for g in geoms {
        reach = reach.max(match g {
            Geom::Point { p } => norm(*p),
            Geom::Circle { frame, r, .. } | Geom::Sphere { frame, r, .. } => norm(frame.o) + r,
            Geom::Ellipse { frame, a, .. } => norm(frame.o) + a,
            Geom::Torus { frame, major, minor, .. } => norm(frame.o) + major + minor,
            Geom::Polyline { points } => points.iter().map(|p| norm(*p)).fold(0.0, f64::max),
            Geom::Mesh { vertices, .. } => vertices.iter().map(|p| norm(*p)).fold(0.0, f64::max),
            _ => 0.0,
        });
    }
    if reach > 0.0 {
        1.5 * reach
    } else {
        5.0
    }
}

/// Fill what a surface's window leaves out: full periods, else ± `extent`.
fn fill_window(geom: &mut Geom, extent: f64) {
    let infinite = [-extent, extent];
    let (u, v) = match geom {
        Geom::Plane { .. } => (infinite, infinite),
        Geom::Cylinder { .. } | Geom::Cone { .. } => ([0.0, TAU], infinite),
        Geom::Sphere { .. } => ([0.0, TAU], [-FRAC_PI_2, FRAC_PI_2]),
        Geom::Torus { .. } => ([0.0, TAU], [0.0, TAU]),
        _ => return,
    };
    if let Some(w) = geom.window_mut() {
        w.u.get_or_insert(u);
        w.v.get_or_insert(v);
    }
}

```rust
//! geomcore types as [`Geom`] (cargo feature `geomcore`).
//!
//! Analytic curves and surfaces keep their exact definition: the frame and radii
//! come from geomcore's getters, so the viewer evaluates the same parametrization
//! (checked against `eval_point` in the tests). B-splines have no wire type yet and
//! are sampled, like the Python client does: a curve as a 256-segment polyline, a
//! surface as a 48 × 48 mesh over its parameter bounds.

use geomcore::curves::{ParametricCurve2D, ParametricCurve3D};
use geomcore::surfaces::ParametricSurface;
use geomcore::{
    BSplineCurve3D, BSplineSurface, Circle2D, Circle3D, Cone, Curve2D, Curve3D, Cylinder, Ellipse3D, Frame3D,
    Hyperbola3D, Line2D, Line3D, Parabola3D, Plane, Point2D, Point3D, Sphere, Surface, Torus, Vector3D,
};

use crate::geom::{cross, Frame, Geom, Vec3};

const BSPLINE_SEGMENTS: usize = 256;
const BSPLINE_GRID: usize = 48;
/// Where a curve or surface of a kind added to geomcore later is sampled when its bounds are infinite.
const UNBOUNDED: f64 = 100.0;

fn p3(p: Point3D) -> Vec3 {
    [p.x, p.y, p.z]
}

fn v3(v: Vector3D) -> Vec3 {
    [v.x, v.y, v.z]
}

fn frame(f: Frame3D) -> Frame {
    Frame { o: p3(f.origin()), x: v3(f.x_direction()), y: v3(f.y_direction()), z: v3(f.z_direction()) }
}

fn sample(eval: impl Fn(f64) -> Vec3, (t0, t1): (f64, f64)) -> Geom {
    let (t0, t1) = (t0.max(-UNBOUNDED), t1.min(UNBOUNDED));
    Geom::polyline((0..=BSPLINE_SEGMENTS).map(|i| eval(t0 + (t1 - t0) * i as f64 / BSPLINE_SEGMENTS as f64)).collect())
}

/// An (n + 1)² vertex grid, two triangles per cell.
fn grid(eval: impl Fn(f64, f64) -> Vec3, (u0, u1): (f64, f64), (v0, v1): (f64, f64)) -> Geom {
    let n = BSPLINE_GRID;
    let (u0, u1, v0, v1) = (u0.max(-UNBOUNDED), u1.min(UNBOUNDED), v0.max(-UNBOUNDED), v1.min(UNBOUNDED));
    let mut vertices = Vec::with_capacity((n + 1) * (n + 1));
    for i in 0..=n {
        for j in 0..=n {
            vertices.push(eval(u0 + (u1 - u0) * i as f64 / n as f64, v0 + (v1 - v0) * j as f64 / n as f64));
        }
    }
    let mut indices = Vec::with_capacity(6 * n * n);
    for i in 0..n {
        for j in 0..n {
            let a = (i * (n + 1) + j) as u32;
            let b = a + (n + 1) as u32;
            indices.extend([a, b, a + 1, a + 1, b, b + 1]);
        }
    }
    Geom::mesh(vertices, indices)
}

impl From<Point3D> for Geom {
    fn from(p: Point3D) -> Geom {
        Geom::point(p3(p))
    }
}

impl From<Point2D> for Geom {
    fn from(p: Point2D) -> Geom {
        Geom::point([p.x, p.y, 0.0])
    }
}

impl From<&Line3D> for Geom {
    fn from(c: &Line3D) -> Geom {
        Geom::line(p3(c.origin()), v3(c.direction()))
    }
}

impl From<&Circle3D> for Geom {
    fn from(c: &Circle3D) -> Geom {
        Geom::circle(frame(c.frame()), c.radius())
    }
}

impl From<&Ellipse3D> for Geom {
    fn from(c: &Ellipse3D) -> Geom {
        Geom::ellipse(frame(c.frame()), c.major_radius(), c.minor_radius())
    }
}

impl From<&Parabola3D> for Geom {
    fn from(c: &Parabola3D) -> Geom {
        Geom::parabola(frame(c.frame()), c.focal())
    }
}

impl From<&Hyperbola3D> for Geom {
    fn from(c: &Hyperbola3D) -> Geom {
        Geom::hyperbola(frame(c.frame()), c.major_radius(), c.minor_radius())
    }
}

impl From<&BSplineCurve3D> for Geom {
    fn from(c: &BSplineCurve3D) -> Geom {
        sample(|t| p3(c.eval_point(t)), c.bounds())
    }
}

impl From<&Curve3D> for Geom {
    fn from(c: &Curve3D) -> Geom {
        match c {
            Curve3D::Line(c) => c.into(),
            Curve3D::Circle(c) => c.into(),
            Curve3D::Ellipse(c) => c.into(),
            Curve3D::Parabola(c) => c.into(),
            Curve3D::Hyperbola(c) => c.into(),
            Curve3D::BSpline(c) => c.into(),
            other => sample(|t| p3(other.eval_point(t)), other.bounds()),
        }
    }
}

/// A 2D line in z = 0 — as a pcurve, its x, y are the surface's u, v.
impl From<&Line2D> for Geom {
    fn from(c: &Line2D) -> Geom {
        let (o, d) = (c.origin(), c.direction());
        Geom::line([o.x, o.y, 0.0], [d.x, d.y, 0.0])
    }
}

/// A 2D circle in z = 0, with its own frame (either handedness: z is x × y).
impl From<&Circle2D> for Geom {
    fn from(c: &Circle2D) -> Geom {
        let f = c.frame();
        let (o, x, y) = (f.origin(), f.x_direction(), f.y_direction());
        let (x, y) = ([x.x, x.y, 0.0], [y.x, y.y, 0.0]);
        Geom::circle(Frame { o: [o.x, o.y, 0.0], x, y, z: cross(x, y) }, c.radius())
    }
}

impl From<&Curve2D> for Geom {
    fn from(c: &Curve2D) -> Geom {
        match c {
            Curve2D::Line(c) => c.into(),
            Curve2D::Circle(c) => c.into(),
            other => sample(
                |t| {
                    let p = other.eval_point(t);
                    [p.x, p.y, 0.0]
                },
                other.bounds(),
            ),
        }
    }
}

impl From<&Plane> for Geom {
    fn from(s: &Plane) -> Geom {
        Geom::plane(frame(s.frame()))
    }
}

impl From<&Cylinder> for Geom {
    fn from(s: &Cylinder) -> Geom {
        Geom::cylinder(frame(s.frame()), s.radius())
    }
}

impl From<&Cone> for Geom {
    fn from(s: &Cone) -> Geom {
        Geom::cone(frame(s.frame()), s.semi_angle(), s.ref_radius())
    }
}

impl From<&Sphere> for Geom {
    fn from(s: &Sphere) -> Geom {
        Geom::sphere(frame(s.frame()), s.radius())
    }
}

impl From<&Torus> for Geom {
    fn from(s: &Torus) -> Geom {
        Geom::torus(frame(s.frame()), s.major_radius(), s.minor_radius())
    }
}

/// A mesh over the surface's parameter bounds.
impl From<&BSplineSurface> for Geom {
    fn from(s: &BSplineSurface) -> Geom {
        grid(|u, v| p3(s.eval_point(u, v)), s.u_bounds(), s.v_bounds())
    }
}

impl From<&Surface> for Geom {
    fn from(s: &Surface) -> Geom {
        match s {
            Surface::Plane(s) => s.into(),
            Surface::Cylinder(s) => s.into(),
            Surface::Cone(s) => s.into(),
            Surface::Sphere(s) => s.into(),
            Surface::Torus(s) => s.into(),
            Surface::BSpline(s) => s.into(),
            other => grid(|u, v| p3(other.eval_point(u, v)), other.u_bounds(), other.v_bounds()),
        }
    }
}

    /// The protocol's parametrizations (`protocol/SCENE.md`), as the viewer evaluates them.
    fn eval_curve(g: &Geom, t: f64) -> Vec3 {
        let at = |f: &Frame, a: f64, b: f64| -> Vec3 { std::array::from_fn(|k| f.o[k] + a * f.x[k] + b * f.y[k]) };
        match g {
            Geom::Line { o, d, .. } => std::array::from_fn(|k| o[k] + t * d[k]),
            Geom::Circle { frame: f, r, .. } => at(f, r * t.cos(), r * t.sin()),
            Geom::Ellipse { frame: f, a, b, .. } => at(f, a * t.cos(), b * t.sin()),
            Geom::Parabola { frame: f, f: focal, .. } => at(f, t * t / (4.0 * focal), t),
            Geom::Hyperbola { frame: f, a, b, .. } => at(f, a * t.cosh(), b * t.sinh()),
            _ => panic!("not a curve: {g:?}"),
        }
    }

    fn eval_surface(g: &Geom, u: f64, v: f64) -> Vec3 {
        let at = |f: &Frame, a: f64, b: f64, c: f64| -> Vec3 {
            std::array::from_fn(|k| f.o[k] + a * f.x[k] + b * f.y[k] + c * f.z[k])
        };
        match g {
            Geom::Plane { frame: f, .. } => at(f, u, v, 0.0),
            Geom::Cylinder { frame: f, r, .. } => at(f, r * u.cos(), r * u.sin(), v),
            Geom::Cone { frame: f, semi_angle, ref_radius, .. } => {
                let radius = ref_radius + v * semi_angle.sin();
                at(f, radius * u.cos(), radius * u.sin(), v * semi_angle.cos())

            Geom::Sphere { frame: f, r, .. } => at(f, r * v.cos() * u.cos(), r * v.cos() * u.sin(), r * v.sin()),
```

```rust
//! Conics and where they meet — the Rust twin of `examples/conics_2d.py`.
//!
//! Run:   python -m geomcore_viewer serve &   (once; any Python viewer script also starts it)
//!        cargo run --example conics --features geomcore
//! Save:  cargo run --example conics --features geomcore -- --save conics.json

use geomcore::{
    Circle3D, CircleConic3DIntersection, Ellipse3D, Frame3D, Hyperbola3D, Line3D, LineCircle3DIntersection,
    LineConic3DIntersection, Point3D, Tolerance, Vector3D,
};
use geomcore_viewer::{Opts, Viewer};

/// The points of a line ∩ conic result.
fn line_conic(hits: LineConic3DIntersection) -> Vec<Point3D> {
    match hits {
        LineConic3DIntersection::Points(a, b) => vec![a.point, b.point],
        LineConic3DIntersection::Tangent(a) => vec![a.point],
        _ => vec![],
    }
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let save = std::env::args().skip_while(|a| a != "--save").nth(1);
    let mut view = Viewer::new("Conics and their intersections")?;
    let tol = Tolerance::DEFAULT;

    let e = Ellipse3D::from_frame(Frame3D::WORLD, 3.0, 2.0)?;
    let c = Circle3D::new(Point3D::new(2.0, 1.0, 0.0), Vector3D::Z, 1.5)?;
    let h = Hyperbola3D::from_frame(Frame3D::WORLD, 1.0, 0.5)?;
    let l = Line3D::new(Point3D::new(0.0, -3.0, 0.0), Vector3D::new(1.0, 1.0, 0.0))?;

    let conics = || Opts::new().group("conics");
    view.add(&e, conics().label("E").extra("foci", true))?;
    view.add(&c, conics().label("C"))?;
    view.add(&h, conics().label("H").extra("asymptotes", true))?;
    view.add(&l, conics().label("L"))?;

    let points = |label: &str| Opts::new().label(label).group("intersections");
    let p = match c.intersect_ellipse(&e, tol) {
        CircleConic3DIntersection::Points(hits) => hits.iter().map(|hit| hit.point).collect(),
        CircleConic3DIntersection::Tangent(hit) => vec![hit.point],
        _ => vec![],
    };
    view.add_all(p, points("P"))?;
    view.add_all(line_conic(l.intersect_ellipse(&e, tol)), points("Q"))?;
    let r = match l.intersect_circle(&c, tol) {
        LineCircle3DIntersection::Points((_, a), (_, b)) => vec![a, b],
        LineCircle3DIntersection::Tangent(_, a) => vec![a],
        _ => vec![],
    };
    view.add_all(r, points("R"))?;
    view.add_all(line_conic(l.intersect_hyperbola(&h, tol)), points("S"))?;

    if let Some(path) = save {
        println!("saved {}", view.save(path)?.display());
    }
    Ok(())
}
```

```rust
//! A circle on a cylinder and its image in the cylinder's (u, v) parameter space.
//!
//! Run:   python -m geomcore_viewer serve &   (once)
//!        cargo run --example pcurve --features geomcore
//! Save:  cargo run --example pcurve --features geomcore -- --save pcurve.json

use geomcore::{Circle3D, Cylinder, Point3D, Vector3D};
use geomcore_viewer::{Opts, ViewMode, Viewer};

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let save = std::env::args().skip_while(|a| a != "--save").nth(1);
    let mut view = Viewer::builder("A circle on a cylinder").view(ViewMode::Space).build()?;

    let cylinder = Cylinder::new(Point3D::ORIGIN, Vector3D::Z, 2.0)?;
    let ring = Circle3D::new(Point3D::new(0.0, 0.0, 1.0), Vector3D::Z, 2.0)?;

    let s = view.add(
        geomcore_viewer::Geom::from(&cylinder).window(None, Some([-2.0, 2.0])),
        Opts::new().label("S").opacity(0.5),
    )?;
    view.add(&ring, Opts::new().label("C"))?;
    // parametrize_on gives the circle's exact image in (u, v): here the line v = 1.
    view.pcurve(&ring.parametrize_on(cylinder)?, &s, Opts::new().label("C in (u, v)"))?;

    if let Some(path) = save {
        println!("saved {}", view.save(path)?.display());
    }
    Ok(())
}
```

````markdown
let s = view.add(Geom::from(&cylinder).window(None, Some([-2.0, 2.0])), Opts::new().label("S"))?;
view.add(&ring, Opts::new().label("C"))?;
view.pcurve(&ring.parametrize_on(cylinder)?, &s, Opts::new().label("C in (u, v)"))?;
```

The viewer server is Python's, and Rust never starts it. Run
`python -m geomcore_viewer serve` once (any Python script using the viewer starts it too).
If no server answers, the client warns once on stderr and keeps the objects;
`view.save("scene.json")` still works.

| Call | Does |
|---|---|
| `Viewer::new(title)`, `Viewer::builder(title).view(ViewMode::Space).keep(true).url(..).build()` | a scene (a new run) |
| `view.add(geom, Opts::new().label("E").group("g").color("#d1495b").width(3.0).dashed(true).opacity(0.5).extra("foci", true))` | show one object → `Handle` |
| `view.add_all(points, Opts::new().label("P"))` | several objects labelled `P₁`, `P₂`, … (an empty list adds the note `P: ∅`) |
| `view.pcurve(curve_2d, &surface_handle, opts)` | a curve in the surface's (u, v) space |
| `view.update(&h, Style::new().color("red"))`, `view.remove(&h)` | change or remove one object |
| `view.clear()`, `view.scene()`, `view.save(path)` | housekeeping |

`Geom` has one variant per protocol type (`Geom::circle(frame, r)`, `.range(t0, t1)` on curves,
`.window(u, v)` on surfaces). With the `geomcore` feature (Rust 1.85+), geomcore's curves,
surfaces, points and `parametrize_on` results convert with `Geom::from(&x)` or pass straight
to `add`. B-splines are sampled: a curve as a 256-segment polyline, a surface as a 48 × 48 mesh.
Intersection results are not mapped; add their points with `add_all`.

`GEOMCORE_VIEWER_URL` picks the server, as for Python (default `http://127.0.0.1:8765`;
a URL without a port means port 80).

Examples (start a server first): `cargo run --example conics --features geomcore`,
`cargo run --example pcurve --features geomcore`; add `-- --save scene.json` to also write the scene to a file.
````
